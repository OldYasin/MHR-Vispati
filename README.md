

# 🚀 mhrv-rs — دور زدن فیلترینگ با اکانت گوگل (رایگان و بی دردسر)

سلام! من **یاسین** هستم. این پروژه در واقع یه ابزار خیلی سبک و جمع‌وجوره که بهت اجازه میده از سرویس رایگان گوگل (Google Apps Script) به عنوان یه پل برای رد شدن از سد فیلترینگ استفاده کنی.

**خلاصه داستان:** این برنامه روی سیستمت اجرا میشه، درخواست‌ها رو می‌فرسته برای یه اسکریپت که توی اکانت گوگل خودت می‌سازی، و گوگل اون سایت رو برات باز می‌کنه. اپراتور اینترنت (همراه اول، ایرانسل و...) فقط می‌بینه که داری به `google.com` وصل میشی، پس کاری به کارت نداره!

---

## ✨ چرا این برنامه؟

* ✅ **کاملاً رایگان:** از سهمیه رایگان روزانه گوگل استفاده می‌کنه.
* ✅ **فوق‌العاده امن:** چون اسکریپت روی اکانت شخصی خودته، کسی به جز خودت و گوگل نمی‌فهمه چیکار می‌کنی.
* ✅ **بدون پیش‌نیاز:** نه پایتون می‌خواد، نه نود جی‌اس. فقط یه فایل ۳ مگابایتی رو اجرا می‌کنی.
* ✅ **همه فن حریف:** روی ویندوز، مک، لینوکس، اندروید و حتی مودم‌های OpenWRT کار می‌کنه.

## 🛠 راهنمای راه‌اندازی (کلا ۵ دقیقه وقتت رو می‌گیره)

### ۱. ساخت اسکریپت در گوگل (فقط یک‌بار)

۱. برو به سایت **[script.google.com](https://script.google.com)** و با جیمیلت وارد شو.
۲. دکمه **New Project** رو بزن.
۳. هر چی کد توی صفحه هست رو پاک کن.
۴. حالا کد فایل [`Code.gs`](https://www.google.com/search?q=assets/apps_script/Code.gs) (توی همین فولدرهای بالا هست) رو کپی کن و اینجا پیست کن.
۵. خط اول یا دوم دنبال `AUTH_KEY` بگرد و اون عبارت `"CHANGE_ME..."` رو پاک کن و یه رمز سخت برای خودت بنویس (مثلاً `MySecret123!@#`). این رمز رو یه جا یادداشت کن.
۶. دکمه 💾 (Save) رو بزن.
۷. حالا از بالا سمت راست روی **Deploy** و بعد **New deployment** کلیک کن.
۸. روی چرخ‌دنده بزن و **Web app** رو انتخاب کن.
۹. تنظیمات رو اینجوری بذار:
*   **Execute as:** Me
*   **Who has access:** Anyone
۱۰. دکمه **Deploy** رو بزن. اگه ازت اجازه خواست (Authorize)، تاییدش کن.
۱۱. در آخر گوگل بهت یه **Deployment ID** میده (یه کد خیلی طولانی). **کپی‌اش کن که لازمش داریم.**

---

### ۲. دانلود و اجرای برنامه

برو به **[صفحه آخرین ریلیزها](https://github.com/therealaleph/MasterHttpRelayVPN-RUST/releases/latest)** و فایل مخصوص سیستم خودت رو دانلود کن:

* ویندوز: `mhrv-rs-windows-amd64.zip`
* مک (تراشه M1/M2/M3): `mhrv-rs-macos-arm64-app.zip`
* اندروید: فایل `.apk`

بعد از دانلود، فایل رو از حالت فشرده خارج کن و اجراش کن:

* **ویندوز:** فایل `run.bat`
* **مک:** فایل `run.command`

توی پنجره‌ای که باز میشه:

* **Apps Script ID:** همون کد طولانی که از گوگل گرفتی رو اینجا بزن.
* **Auth key:** همون رمزی که توی مرحله قبل خودت تعیین کردی.
* حالا دکمه **Save** و بعد **Start** رو بزن. اگه دایره سبز شد، یعنی همه‌چی ردیفه!

---

### ۳. تنظیم مرورگر (مرحله آخر)

حالا باید به مرورگرت بگی که از این برنامه استفاده کنه:

* **روش پیشنهادی (فایرفاکس):**
برو توی Settings، سرچ کن Proxy، بعد روی Settings بزن. گزینه **Manual proxy** رو انتخاب کن و توی بخش HTTP Proxy بنویس: `127.0.0.1` و پورت رو بذار `8085`. تیک "Also use this proxy for HTTPS" رو هم حتماً بزن.
* **روش راحت (کروم/اج):**
افزونه [SwitchyOmega](https://chromewebstore.google.com/detail/proxy-switchyomega/padekgcemlokbadohgkifijomclgjgif) رو نصب کن و یه پروکسی با آدرس `127.0.0.1` و پورت `8085` بساز.

## 🧐 چند نکته مهم (سوالات متداول)

* **چرا یوتیوب فیلم پخش نمی‌کنه؟**
گوگل اجازه نمیده اسکریپت‌هاش به سرورهای ویدیو (googlevideo.com) وصل بشن. صفحه یوتیوب باز میشه ولی ویدیو نه. برای حل این مشکل باید از حالت "Full Tunnel" استفاده کنی که نیاز به سرور شخصی داره.
* **چرا تلگرام وصل نمیشه؟**
تلگرام پروتکل خاص خودش رو داره. اگه می‌خوای تلگرام هم اوکی بشه، باید این برنامه رو با `Xray` ست کنی (توی راهنمای کامل توضیح دادم).
* **امنیتش چطوره؟**
خیلی خوبه. کلیدی که اول کار برای خودت ساختی باعث میشه هیچ‌کس نتونه از اسکریپت تو استفاده کنه. گواهی امنیتی هم فقط روی سیستم خودت معتبره.
